## Generics

Generics, em TypeScript, são uma ferramenta poderosa que permite criar componentes que podem trabalhar com diferentes tipos de dados sem perder a flexibilidade e a segurança.

O principal problema que os generics resolvem é a necessidade de reutilização de código, permitindo que funções e classes operem em diferentes tipos enquanto mantêm a integridade dos tipos.

Um exemplo simples de um uso de generics seria em uma função que retorna o valor de uma chave de um objeto. Sem generics, você teria que especificar um tipo fixo, mas com generics, você pode definir que qualquer tipo pode ser usado.
